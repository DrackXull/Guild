# Firebase Studio

This is a NextJS starter in Firebase Studio.

To get started, take a look at src/app/page.tsx.

## Roadmap

*   **DarkerDB API Integration:** Investigate and potentially integrate with the DarkerDB API (`https://api.darkerdb.com/`) to pull live character data, stats, and item information directly into the guild hub. This could enable automated stat tracking, character verification, and a more connected experience with the live game.
